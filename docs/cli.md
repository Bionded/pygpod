# Command line

`pygpod` is the command line front end of the library. It takes the mount point from
`-m/--mountpoint` or the `PYGPOD_MOUNTPOINT` environment variable. Exit codes: 0 success,
1 error (for `doctor`: issues found), 2 bad arguments.

| task | commands |
|---|---|
| look | `info`, `track list`, `track info <id>`, `playlist list`, `dump`, `discover` |
| music | `track add <files>` (tags read; `--title`, `--artist` ... override; `--type` for podcasts, audiobooks, video; `--soundcheck auto\|analyze`), `track remove`, `track export` |
| playlists | `playlist create`, `add`, `remove`, `delete` |
| maintenance | `doctor [--no-verbose]`, `doctor --fix [--delete-orphans]`, `backup`, `restore [--dry-run] [--force]`, `fix-checksums` |
| set up | `init [--model] [--music-dirs]`, `purge --yes` |

Conversion, `set_artwork()`, photos and smart playlists are available from Python only (covers
embedded in the files are imported by `track add` too).

### `pygpod`

```text
usage: pygpod [-h] [--debug] [-m MOUNTPOINT]
              {info,i,track,tr,playlist,pl,dump,init,fix-checksums,purge,discover,doctor,backup,restore} ...

pygpod - Python iPod database manager

positional arguments:
  {info,i,track,tr,playlist,pl,dump,init,fix-checksums,purge,discover,doctor,backup,restore}
                        command
    info (i)            Show iPod info and playlists
    track (tr)          Track operations
    playlist (pl)       Playlist operations
    dump                Dump raw iTunesDB structure
    init                Initialize iPod directory structure
    fix-checksums       Recalculate database checksums
    purge               Delete all data from iPod
    discover            Auto-detect connected iPods
    doctor              Check the database and media for inconsistencies (read-only)
    backup              Back up the iPod to a tar archive
    restore             Restore a backup archive onto the iPod

options:
  -h, --help            show this help message and exit
  --debug, -d           Enable debug logging
  -m, --mountpoint MOUNTPOINT
                        iPod mount point (default: $PYGPOD_MOUNTPOINT)

environment:
  PYGPOD_MOUNTPOINT    Default iPod mount point

aliases:
  i = info, tr = track, pl = playlist, ls = list, rm = remove

examples:

  Setup & info:
    pygpod -m /mnt/ipod init                     Initialize a new iPod
    pygpod -m /mnt/ipod init --music-dirs 10     Init with 10 music dirs
    export PYGPOD_MOUNTPOINT=/mnt/ipod           Set default mountpoint
    pygpod info                                  Show device & track summary

  Adding music:
    pygpod tr add song.mp3                       Add a track (tags auto-read)
    pygpod tr add *.mp3                          Add multiple files at once
    pygpod tr add song.mp3 --artist 'Beatles' --album 'Abbey Road'
    pygpod tr add song.mp3 --title 'Hey Jude' --genre Rock --year 1968
    pygpod tr add song.mp3 --track-number 1 --total-tracks 12

  Podcasts (auto-creates playlist by category):
    pygpod tr add ep01.mp3 --type podcast --category 'Tech News'
      -> creates 'Tech News' podcast playlist, adds track to it
    pygpod tr add ep02.mp3 --type podcast --category 'Tech News'
      -> adds to existing 'Tech News' playlist automatically
    pygpod tr add ep.mp3 --type podcast
      -> adds to default 'Podcasts' playlist
    pygpod tr add ep.mp3 --type podcast --description 'Episode about AI'

  Video & TV shows:
    pygpod tr add clip.m4v --type video
    pygpod tr add episode.m4v --type tvshow --tvshow 'Breaking Bad' \
        --season-number 1 --episode-number 1
    pygpod tr add clip.m4v --type musicvideo --artist 'Radiohead'

  Audiobooks:
    pygpod tr add chapter1.m4b --type audiobook --title 'Chapter 1'

  Browsing & filtering tracks:
    pygpod tr ls                                 List all tracks
    pygpod tr ls --type podcast                  List podcasts only
    pygpod tr ls --genre Jazz                    Filter by genre
    pygpod tr ls --artist Beatles                Filter by artist
    pygpod tr ls --category 'Tech News'          Filter by category
    pygpod tr info 52                            Show full details for track 52

  Managing tracks:
    pygpod tr rm 52                              Remove track from database
    pygpod tr rm 52 --delete-file                Also delete file from iPod
    pygpod tr export 52 ~/Music/song.mp3         Copy track off iPod

  Playlists:
    pygpod pl ls                                 List all playlists
    pygpod pl ls --podcast                       List podcast playlists only
    pygpod pl create 'Road Trip'                 Create a normal playlist
    pygpod pl create 'My Podcast' --podcast      Create a podcast playlist
    pygpod pl add 'Road Trip' 52 53 54           Add tracks to playlist
    pygpod pl rm 'Road Trip' 52                  Remove track from playlist
    pygpod pl delete 'Road Trip'                 Delete entire playlist

  Maintenance:
    pygpod fix-checksums                         Recalculate DB checksums
    pygpod dump                                  Dump raw DB structure
    pygpod purge --yes                           Wipe all data from iPod
    pygpod doctor                                Check the database (read-only)
    pygpod doctor --fix                          Repair what can be repaired
    pygpod backup ipod.tar.gz                    Back up database + media
    pygpod restore ipod.tar.gz --dry-run         Check a backup, plan a restore
    pygpod discover                              Auto-detect connected iPods
```

### `pygpod track add`

```text
usage: pygpod track add [-h] [--title TITLE] [--artist ARTIST] [--album ALBUM] [--genre GENRE]
                        [--composer COMPOSER] [--comment COMMENT] [--albumartist ALBUMARTIST]
                        [--grouping GROUPING] [--year YEAR] [--track-number TRACK_NUMBER]
                        [--total-tracks TOTAL_TRACKS] [--cd-number CD_NUMBER]
                        [--total-cds TOTAL_CDS]
                        [--type {audio,video,podcast,audiobook,musicvideo,tvshow}]
                        [--category CATEGORY] [--description DESCRIPTION] [--subtitle SUBTITLE]
                        [--keywords KEYWORDS] [--podcast-url PODCAST_URL]
                        [--podcast-rss PODCAST_RSS] [--tvshow TVSHOW] [--tvepisode TVEPISODE]
                        [--tvnetwork TVNETWORK] [--season-number SEASON_NUMBER]
                        [--episode-number EPISODE_NUMBER] [--soundcheck {auto,analyze}]
                        files [files ...]

positional arguments:
  files                 Audio/video files to add

options:
  -h, --help            show this help message and exit
  --soundcheck {auto,analyze}
                        Sound Check by ffmpeg loudness analysis: 'auto' only for files without
                        ReplayGain/iTunNORM tags, 'analyze' for every file (default: tags only)

metadata overrides:
  --title TITLE         Track title
  --artist ARTIST       Artist name
  --album ALBUM         Album name
  --genre GENRE         Genre
  --composer COMPOSER   Composer
  --comment COMMENT     Comment
  --albumartist ALBUMARTIST
                        Album artist
  --grouping GROUPING   Grouping
  --year YEAR           Year
  --track-number TRACK_NUMBER
                        Track number
  --total-tracks TOTAL_TRACKS
                        Total tracks in album
  --cd-number CD_NUMBER
                        Disc number
  --total-cds TOTAL_CDS
                        Total discs

media type:
  --type {audio,video,podcast,audiobook,musicvideo,tvshow}
                        Media type (default: auto-detect or audio)

podcast/video metadata:
  --category CATEGORY   Category (e.g. News, Sports)
  --description DESCRIPTION
                        Episode description
  --subtitle SUBTITLE   Subtitle
  --keywords KEYWORDS   Keywords/tags
  --podcast-url PODCAST_URL
                        Podcast episode URL
  --podcast-rss PODCAST_RSS
                        Podcast feed RSS URL
  --tvshow TVSHOW       TV show name
  --tvepisode TVEPISODE
                        TV episode identifier
  --tvnetwork TVNETWORK
                        TV network name
  --season-number SEASON_NUMBER
                        Season number
  --episode-number EPISODE_NUMBER
                        Episode number
```

### `pygpod restore`

```text
usage: pygpod restore [-h] [--no-media] [--dry-run] [--force] archive

positional arguments:
  archive     Archive written by 'pygpod backup'

options:
  -h, --help  show this help message and exit
  --no-media  Restore the database only
  --dry-run   Verify the archive and show the plan only
  --force     Restore a backup of another iPod (keeps this iPod's SysInfo, re-signs the DB)
```
