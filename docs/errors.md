# Errors

Every exception pygpod raises on purpose derives from `PyGpodError`, so one `except` catches them
all; the subclasses tell what went wrong (see the reference below). The ones callers usually
handle:

- `MountPointError`: the path is not an iPod (no `iPod_Control`);
- `TrackError` / `UnsupportedFormatError`: a file cannot be added (pass `convert=True` to convert
  instead of refusing); `UnsafePathError` (also a `ValueError`): a path outside the mount point;
- `HashError`: the database cannot be signed (missing FirewireGuid or HashInfo, unsupported
  scheme); nothing was written;
- `ConflictError`: another program saved the database meanwhile; reopen, or `save(force=True)`;
- `ArtworkDBError`: the ArtworkDB is damaged; covers cannot change until `reset_artwork()`;
- `BackupError`: an archive is damaged or does not fit this iPod.

```python
import pygpod

try:
    pygpod.Database(f"{workdir}/not-an-ipod")
except pygpod.PyGpodError as e:
    print(type(e).__name__, e)
```

### `pygpod.PyGpodError`

```text
Base exception for all pygpod errors.
```

### `pygpod.DatabaseError`

```text
Error parsing or writing an iPod database.
```

### `pygpod.ParseError`

```text
Error parsing a binary database file.
```

### `pygpod.WriteError`

Base: `DatabaseError`

```text
Error writing a binary database file.
```

### `pygpod.ConflictError`

Base: `WriteError`

```text
The database on the iPod changed since it was loaded, or another writer holds the lock.
```

### `pygpod.DeviceError`

### `pygpod.ArtworkError`

Base: `PyGpodError`

```text
Error related to artwork operations.
```

### `pygpod.ArtworkDBError`

Base: `ArtworkError`

```text
The ArtworkDB on the iPod exists but cannot be read (corrupt or an I/O error).

Cover art cannot be added or changed until ``Database.reset_artwork()`` replaces it
with an empty one; saving tracks without artwork changes still works and leaves the
file as it is.
```

### `pygpod.DependencyError`

Base: `PyGpodError`

```text
A required optional dependency is not installed.
```

### `pygpod.UnsupportedFormatError`

Base: `TrackError`

```text
Audio/video format not supported by iPod.

The file must be converted to a supported format (MP3, AAC, ALAC, WAV, AIFF)
before adding to the iPod, or added with ``add_track(..., convert=True)`` (ffmpeg).
```

### `pygpod.UnsafePathError`

Base: `PyGpodError`, `ValueError`

```text
A path read from the database would point outside the iPod mount point.
```

### `pygpod.BackupError`

Base: `PyGpodError`

```text
A backup could not be written, or an archive cannot be restored.
```
