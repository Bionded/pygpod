# Playlists and smart playlists

A playlist is an ordered list of tracks. Every database has one master playlist
(`db.master_playlist`, the library) that holds every track and is maintained by pygpod. A podcast
playlist (`create_playlist(name, podcast=True)`) groups episodes by show, as the iPod's Podcasts
menu expects. Smart playlists store rules (MHOD 51) and preferences (MHOD 50); pygpod evaluates
them like libgpod, and live-updating ones are refreshed on every `save()`.

```python
import pygpod
from pygpod import SPLAction, SPLField, SPLMatch, SPLRule, evaluate_smart_playlist

db = pygpod.Database(mountpoint)
a = db.add_track(song, title="Один", genre="Rock")
b = db.add_track(song, title="Два", genre="Jazz")
mix = db.create_playlist("Мікс")
db.add_track_to_playlist(mix, b)
db.add_track_to_playlist(mix, a)

rock = SPLRule(field=SPLField.GENRE, action=SPLAction.CONTAINS, string="Rock")
assert [t.title for t in evaluate_smart_playlist([rock], SPLMatch.AND, db.tracks)] == ["Один"]
smart = db.create_smart_playlist("Rock", [rock])
db.save()
db = pygpod.Database(mountpoint)
assert [t.title for t in db.get_playlist("Rock").tracks] == ["Один"]
assert [t.title for t in db.get_playlist("Мікс").tracks] == ["Два", "Один"]
```

- `set_playlist(name, tracks)` creates a playlist or replaces its members (handy for syncing);
  `get_playlist(name)` finds one, `delete_playlist()` / `delete_playlist_by_name()` remove them.
- Removing a track removes it from every playlist.
- `SPLPrefs` sets live updating, whether the rules are checked, "only checked tracks" and a limit
  (count, size or time, with an `SPLLimitSort` order); `update_smart_playlist()` changes rules
  and preferences, `refresh_smart_playlist()` re-evaluates one now.
- On-The-Go playlists made on the iPod are described in [playcounts.md](playcounts.md).

### `pygpod.evaluate_smart_playlist(rules: 'List[SPLRule]', match: 'SPLMatch', tracks: "List['Track']", playlists: 'Optional[Mapping[int, Set[int]]]' = None) -> "List['Track']"`

```text
Evaluate all rules against all tracks and return matching ones.

Args:
    rules: List of SPL rules.
    match: SPLMatch.AND or SPLMatch.OR.
    tracks: List of tracks to evaluate.
    playlists: playlist id -> member track ids (for playlist rules).

Returns:
    List of tracks that match the rules.
```
