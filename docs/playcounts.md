# Play counts and On-The-Go playlists

## Play counts

Between syncs the iPod does not change the iTunesDB: it records plays, skips, ratings and
bookmarks in a separate file (`Play Counts`; `iTunesStats` on the shuffles, `PlayCounts.plist` on
some models). By default `Database()` merges them into the tracks when it opens; the file is
deleted only after the next successful `save()`, so a session that does not save loses nothing.
With `apply_play_counts=False` they are only read, and the caller decides:

```python
import pygpod

db = pygpod.Database(mountpoint, apply_play_counts=False)
for p in db.pending_play_counts():   # PendingPlayCount(track, play_count, ...)
    print(p.track.title, p.play_count)
db.merge_play_counts()               # or db.clear_play_counts()
```

## On-The-Go playlists

On-The-Go playlists made on the iPod (`OTGPlaylistInfo`, `OTGPlaylistInfo_1`, ...) store track
*positions* in the iTunesDB, so they become wrong as soon as a save reorders the tracks.
`DatabaseConfig.otg_on_save` decides what a save does with them:

- `"import"` (default, like iTunes and libgpod): each becomes a normal playlist "OTG Playlist n"
  and the files are removed; the iPod's On-The-Go list is empty afterwards;
- `"keep"`: the files stay and their positions are rewritten to follow the tracks (the iPod
  Classic empties such a list anyway once the database changed);
- `"clear"`: the files are removed without importing.

`pending_otg_playlists()` shows them as track lists (entries whose track or file is bad are left
out, see `otg_skipped_entries()`), `import_otg_playlists(name=...)` and `clear_otg_playlists()`
handle them explicitly before a save.

```python
db = pygpod.Database(mountpoint)
print(db.pending_otg_playlists(), db.otg_skipped_entries())
print(pygpod.read_otg_playlists(mountpoint), len(pygpod.read_play_counts(mountpoint)))
```

## Reference

_Generated by `docs/gen_reference.py` from the docstrings._

### `pygpod.read_play_counts(mountpoint: 'str') -> 'List[PlayCountEntry]'`

```text
Read play count data from an iPod mount point.

Uses the first file found in libgpod's order: Play Counts, iTunesStats,
PlayCounts.plist.

Args:
    mountpoint: iPod mount point path.

Returns:
    List of PlayCountEntry, or empty list if none found.
```

### `pygpod.PendingPlayCount`

Fields: `track, play_count, time_played, rating, skip_count, time_skipped, bookmark_time`

```text
A play count update read from the iPod, matched to its track.

Values are as written by the iPod: ``play_count`` and ``skip_count`` are
increments since the last sync, the others are absolute values
(0 / -1 for rating = not set).
```

### `pygpod.read_otg_playlists(mountpoint: 'str') -> 'List[List[int]]'`

```text
Read OTG playlists from an iPod mount point (every numbered file).

Args:
    mountpoint: iPod mount point path.

Returns:
    List of playlists (each a list of track indices); empty files are left out.
```

### `pygpod.OTGSkippedEntry`

Fields: `file, position, index, reason`

```text
An On-The-Go entry left out of the import because its track or file is bad.
```
