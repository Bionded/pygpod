# Tags, conversion, Sound Check, gapless, chapters

## Tags

`add_track()` reads the file's tags with mutagen (the `tags` extra): ID3 (MP3), MP4 atoms
(M4A/M4B/M4V) and Vorbis comments (FLAC, Ogg). Besides title, artist, album, genre, year and
numbers it takes the sort tags, compilation, rating (POPM / FMPS_RATING / RATING), BPM, grouping,
explicit/clean, description, release date, category, keywords, the podcast URL and episode GUID,
the embedded cover and, for video, the TV atoms (`tvsh`, `tven`, `tvnn`, `tvsn`, `tves`) and
the iTunes media kind. `pygpod.tags.read_tags()` returns that mapping; keyword arguments of
`add_track()` always win over it.

## Format check and conversion

`add_track()` checks the *content* of a file (not just its extension) against what the iPod model
plays. With `convert=True` (needs ffmpeg, plus ffprobe for video) it converts instead of refusing:

- audio: lossless sources become Apple Lossless where the model plays it, everything else AAC;
  more than 48 kHz or 2 channels are reduced;
- video (iPods that play video): anything outside the model's H.264 profile becomes an .m4v with
  H.264 Baseline and AAC-LC stereo, inside 320x240 (`video_size="small"`, default) or 640x480
  (`video_size="large"`: 5.5G, nano 3G-5G, Classic); video that fits is copied unchanged.

```python
import pygpod
from pygpod import convert, gapless, tags

info = tags.read_tags(song)
print(info["title"], info["duration_ms"], info.get("soundcheck"), gapless.read_gapless(song))
assert tags.soundcheck_from_gain(-6.5) == 4467
profile = convert.video_profile(pygpod.Device.from_mountpoint(mountpoint).generation)
assert (profile.max_width, profile.max_height) == (640, 480)
```

```py
db.add_track("movie.mkv", convert=True, video_size="large")
db.add_track("song.flac", convert=True)
```

## Sound Check

Sound Check (the iPod's volume levelling) comes from iTunNORM or ReplayGain
(`REPLAYGAIN_TRACK_GAIN` / `_ALBUM_GAIN`) tags; `soundcheck=` sets it explicitly
(`tags.soundcheck_from_gain(dB)` converts a gain). Files without such tags get no Sound Check unless it is measured: with
`soundcheck="auto"` ffmpeg's `replaygain` filter measures files that have no gain tags,
`soundcheck="analyze"` measures every file (the converted one with `convert=True`), and
`Database.analyze_soundcheck()` measures tracks already on the iPod. About 150x realtime on a
Raspberry Pi 5 (a 4-minute track takes ~1.5 s).

```py
db.add_track("live.mp3", soundcheck="auto")
db.analyze_soundcheck(only_missing=True, progress=lambda done, total, t: print(done, total))
db.save()
```

## Gapless playback

The gapless fields (`pregap`, `postgap`, `sample_count`, `gapless_data`, the track and album
flags) come from the LAME/Info tag (MP3), iTunSMPB or the MP4 edit list (AAC); the `pgap` atom
sets the album flag. MP3s without a LAME/Info tag get no gapless data, so continuous albums play with a short gap.
`gapless="estimate"` (or `"auto"`) estimates it (experimental): frames are counted, LAME's
576-sample encoder delay is assumed and the padding is measured by decoding the last frames
with ffmpeg (without ffmpeg the padding stays 0 and the gapless flag is not set). For AAC
without iTunSMPB or edit list the encoder delay is assumed (1024 samples for ffmpeg's encoder,
else Apple's 2112) and the padding taken from the last packet's duration. Files with a valid
LAME/Info tag, iTunSMPB or edit list always use their exact data; `gapless={...}` sets values.
ALAC has no encoder delay or padding: without iTunSMPB (e.g. converted by ffmpeg) its sample
count is the track's length.

```py
db.add_track("live-02.mp3", gapless="estimate", gapless_album_flag=True)
```

## Chapters

Chapters of audiobooks and podcasts are imported too (`pygpod.chapters.read_chapters`): the
MP4 chapter track or Nero `chpl` atom (M4B/M4A), ID3 `CHAP` frames in `CTOC` order (MP3). They
become the track's chapter data (MHOD 17, the bytes libgpod writes). `chapters=` overrides them:

```py
book = db.add_track("book.m4b")                 # chapters from the file
print(book.chapters.to_list())                  # [(1, 'Розділ 1'), (754000, 'Розділ 2'), ...]
db.add_track("talk.mp3", chapters=[(0, "Вступ"), (90000, "Обійми")])
db.add_track("song.mp3", chapters=[])           # no chapters
book.chapters = None                            # remove them
```

### `pygpod.convert.convert_for_ipod(filepath: 'str', generation=None, aac_bitrate: 'str' = '256k', workdir: 'Optional[str]' = None, video_size: 'str' = 'small') -> 'str'`

```text
Convert ``filepath`` to an .m4a (or, for video, .m4v) the iPod plays.

Returns the path of a new temporary file (the caller deletes it). Tags are copied as far as
ffmpeg maps them; embedded pictures are not (add_track reads tags and artwork from the
original). A file with a video stream (found by ffprobe; cover pictures do not count)
goes to convert_video_for_ipod(size=video_size) when the iPod plays video or the
generation is unknown. Raises UnsupportedFormatError when ffmpeg is missing or fails.
```

### `pygpod.convert.convert_video_for_ipod(filepath: 'str', generation=None, size: 'str' = 'small', workdir: 'Optional[str]' = None, probe: 'Optional[Dict[str, Any]]' = None) -> 'str'`

```text
Convert a video to an .m4v the iPod plays (H.264 Baseline + AAC-LC stereo).

``size="small"``: inside 320x240, Level 1.3, <= 768 kbps (every video iPod).
``size="large"``: inside 640x480, Level 3.0, <= 1.5 Mbps where the generation plays it
(5.5G, nano 3G-5G, Classic), else small. Keeps the aspect ratio, never upscales, caps
the frame rate at 30 fps. Returns a new temporary file (the caller deletes it). Raises
UnsupportedFormatError when the iPod plays no video, ffmpeg is missing or fails.
```

### `pygpod.tags.read_soundcheck(filepath: 'str') -> 'Optional[int]'`

```text
Sound Check value from a file's tags, None if it has none (or mutagen is missing).

iTunNORM (ID3 COMM / MP4 freeform; the larger of its first two hex values, as iTunes
and gtkpod read it) wins, then REPLAYGAIN_TRACK_GAIN, then REPLAYGAIN_ALBUM_GAIN (ID3
TXXX, MP4 freeform, Vorbis/FLAC comments, APEv2).
```

### `pygpod.tags.soundcheck_from_gain(gain_db: 'float') -> 'int'`

```text
Sound Check value for a ReplayGain-style gain in dB (gtkpod/libgpod formula):
round(1000 * 10^(-gain_dB / 10)), kept within 1 .. 2^32-1 (0 means "no Sound Check").
```

```text

Args:
```

### `pygpod.gapless.estimate_mp3_gapless(filepath: 'str', use_ffmpeg: 'bool' = True) -> 'Optional[Dict[str, int]]'`

```text
Estimated gapless fields of an MP3 without a valid LAME/Info tag (experimental).

The frames are counted (sample total and ``gapless_data`` as for tagged files), the
encoder delay is assumed to be LAME's (576 samples, the value its info tag stores; other
encoders publish no delay) and the padding at the end is measured by decoding only the
last frames with ffmpeg: the run of samples below -90 dBFS (at most two frames) plus
the 529-sample decoder delay.
Without ffmpeg (or ``use_ffmpeg=False``) the padding is taken as 0 and
``gapless_track_flag`` is not set, because the estimate is incomplete.

Returns:
    The gapless fields, or None for non-MP3 files, files with a valid LAME/Info tag
    (use read_mp3_gapless) and files without MPEG audio frames.
```

### `pygpod.gapless.mp3_stream_info(filepath: 'str') -> 'Optional[Dict[str, int]]'`

```text
Duration and average bitrate of an MP3 from a scan of all its frames.

For MP3s without a Xing/Info/VBRI header, where a length estimated from the first frame's
bitrate is wrong for VBR files. A Xing/Info frame, if any, is not counted.

Returns:
    ``{"duration_ms": ..., "bitrate": kbps, "samplerate": Hz}``, or None for files without
    MPEG audio frames.
```

### `pygpod.gapless.estimate_mp4_gapless(filepath: 'str') -> 'Optional[Dict[str, int]]'`

```text
Estimated gapless fields of an AAC MP4 without iTunSMPB or edit list (experimental).

The encoder delay is assumed: 1024 samples for files written by ffmpeg (``©too``
"Lavf...", its native AAC encoder), else 2112 (Apple's). The padding is what the last
packet's stts duration leaves out of a whole frame (ffmpeg shortens it to the real end);
only then is ``gapless_track_flag`` set, else the padding is unknown and taken as 0.

Returns:
    The gapless fields, or None for other files, files with exact data (read_mp4_gapless)
    and ALAC.
```
