# Tracks

A `Track` is one song, video, podcast episode or audiobook (an MHIT record). String properties
(title, artist, sort fields, podcast and TV fields ...) and numbers and flags (rating, play count,
track number, Sound Check, gapless data ...) are settable; setting one marks the database
modified and `save()` writes it. Structural fields (ids, file path, size, bitrate, length) are
read-only.

```python
import pygpod
from pygpod.db.constants import MEDIATYPE_PODCAST

db = pygpod.Database(mountpoint)
t = db.add_track(song, title="Обійми", artist="Океан Ельзи", track_number=3, total_tracks=12)
t.rating_stars = 5        # rating = 100
t.play_count = 5
t.sort_title = "Обійми (live)"
t.compilation = False
db.save()

t = pygpod.Database(mountpoint).tracks[-1]
assert (t.rating, t.play_count, t.track_number) == (100, 5, 3)
print(t.media_type, t.duration_ms, t.file_size, t.ipod_path, t.time_added)
t.media_type = MEDIATYPE_PODCAST   # also sets the podcast flags
assert t.is_podcast
```

Where the values come from when a file is added (see [media.md](media.md)): its tags (mutagen,
the `tags` extra) for the metadata, sort fields, rating, compilation, BPM, release date and
embedded cover; iTunNORM / ReplayGain tags for Sound Check; LAME/Info tags, iTunSMPB and MP4 edit
lists for the gapless fields; MP4 chapter tracks, Nero `chpl` and ID3 `CHAP` frames for chapters;
the MP4 video track and iTunes atoms for the media type and TV fields. Keyword arguments of
`add_track()` always win.

- **Media type**: `media_type` takes the `MEDIATYPE_*` values of `pygpod.db.constants` (audio,
  video, podcast, audiobook, music video, TV show, home video); `is_podcast`, `is_audiobook`,
  `is_video` follow from it.
- **Times** (`time_added`, `time_played`, `time_released` ...) are aware `datetime`s in UTC;
  the iPod stores its local time (see [database.md](database.md#timestamps)).
- **Chapters**: `track.chapters` is a `ChapterData` (or None); assign a list of
  `(start_ms, title)` tuples to replace them, `None` to remove them.
